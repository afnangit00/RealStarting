# Afnan Cheranthodika — Creative Developer Portfolio

Premium responsive portfolio covering the photographer, videographer and designer website categories.

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Next/Image

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Important: add your real social links
Edit `app/page.tsx` and replace:
- `https://wa.me/REPLACE_WITH_YOUR_NUMBER`
- `https://www.instagram.com/REPLACE_WITH_YOUR_USERNAME/`
- `https://www.linkedin.com/in/REPLACE_WITH_YOUR_PROFILE/`

WhatsApp URL format: `https://wa.me/` followed by your international number, digits only (no `+`, spaces or dashes).

The old portfolio and email are prefilled:
- https://afnancheranthodika.vercel.app/
- afnancheranthodika@gmail.com

The three project cards currently showcase the three template categories. Connect them to live project URLs after deployment.

The supplied Instagram CDN profile image URL is used in the hero. CDN URLs can expire or block hotlinking; for production, put your profile image in `public/afnan-profile.jpg` and update `profileImage` to `/afnan-profile.jpg`.

Deploy on Vercel with the default Next.js settings.
